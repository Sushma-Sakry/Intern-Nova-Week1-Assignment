# Intern Nova - Week 1 Assignment
## Python Fundamentals for Data Analytics

This repository contains my **Intern Nova Week 1 Assignment** on **Python Fundamentals for Data Analytics**.

The assignment focuses on building a strong foundation in Python programming through practical coding tasks.

## Topics Covered

- Introduction to Python
- Variables and Data Types
- Operators
- Conditional Statements
- For and While Loops
- Functions
- Strings
- Lists
- Tuples
- Dictionaries
- Sets
- Basic File Handling
- Student Record Management System (Mini Project)

## Project Files

| Tasks | Description |
|------|-------------|
| Task 1 Python Basics | Basic Python program with user input and formatted output |
| Task 2 Variables Data Types | Demonstrates variables and different Python data types |
| Task 3 Calculator | Performs basic arithmetic operations |
| Task 4 Conditional Statements | Assigns grades using if, elif and else |
| Task 5 Loops | Demonstrates for and while loops |
| Task 6 Functions | Demonstrates user-defined functions for square and average |
| Task 7 Strings Collections | Demonstrates strings, lists, tuples, dictionaries and sets |
| Task 8 File Handling | Creates, writes, reads and displays a text file |
| Task 9 Student Record Management | Mini project for managing student records |

## Technologies Used

- Python
- Google Colab

## Objective

The objective of this assignment is to develop practical knowledge of fundamental Python concepts and apply them to simple data analytics-oriented programming tasks.
