# Intern Nova - Week 1 Assignment
## Python Fundamentals for Data Analytics

This repository contains my **Intern Nova Week 1 Assignment** on **Python Fundamentals for Data Analytics**.

The assignment focuses on building a strong foundation in Python programming through practical coding tasks.

## Topics Covered

- Introduction to Python
- Variables and Data Types
- Operators
- Conditional Statements
- For and While Loops
- Functions
- Strings
- Lists
- Tuples
- Dictionaries
- Sets
- Basic File Handling
- Student Record Management System (Mini Project)

## Project Files

| File | Description |
|------|-------------|
| `Task1_Python_Basics.py` | Basic Python program with user input and formatted output |
| `Task2_Variables_DataTypes.py` | Demonstrates variables and different Python data types |
| `Task3_Calculator.py` | Performs basic arithmetic operations |
| `Task4_Conditional_Statements.py` | Assigns grades using if, elif and else |
| `Task5_Loops.py` | Demonstrates for and while loops |
| `Task6_Functions.py` | Demonstrates user-defined functions for square and average |
| `Task7_Strings_Collections.py` | Demonstrates strings, lists, tuples, dictionaries and sets |
| `Task8_File_Handling.py` | Creates, writes, reads and displays a text file |
| `Task9_Student_Record_Management.py` | Mini project for managing student records |

## Technologies Used

- Python 3
- Google Colab

## Objective

The objective of this assignment is to develop practical knowledge of fundamental Python concepts and apply them to simple data analytics-oriented programming tasks.
